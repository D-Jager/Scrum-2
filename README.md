Dit is een van de paar scrumprojecten waar ik aan heb gewerkt. Dit is de tweede die ik ooit heb gemaakt, en kan wel zeggen dat ik hier minder heb gedaan dan ik echt kan.

Hierbij heb ik er ook voor moeten zorgen dat het leaderboard erbij word gehaald, en dat het spel pauzeert. Alle code hierbij is door mij geschreven, de rest is allemaal door mijn scrum-team gemaakt.

Het was een leuk project, en kan zeggen dat ik hier veel plezier mee heb gehad.
